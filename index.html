Featured projects

JavaScript web app · Personal project

Interactive World Map

A clickable SVG world map: hover to highlight a country, click to see its capital, area, currency and languages, fetched live from a public REST API.

How it works

  • Uses JavaScript DOM APIs to add hover and click handling to every country path in the SVG.
  • Fetches country data from the countries.dev REST API with the Fetch API and handles failed HTTP responses.
  • Some country names return several records, so the matching logic prefers an exact name match, then the most populous partial match, then falls back to the first result.
  • Updates the info panel from the JSON response, with “N/A” fallbacks for missing fields.
  • JavaScript
  • SVG
  • Fetch API
  • REST
  • HTML/CSS

Android app · WGU capstone · 2025–2026

Vacation Planner

An offline Android app for planning vacations and the excursions within each trip, with search, reminders and business-rule validation.

How it works

  • Built in Java with Android Studio.
  • Local SQLite database built with Room, with full CRUD and relational integrity between vacation and excursion entities.
  • Real-time vacation search, and AlarmManager notifications for upcoming trips and excursions.
  • Input sanitization, character limits and date validation enforce the app’s business rules.
  • Unit tests cover date validation, entity creation and business rules. Version control and CI/CD ran on GitLab.
  • Java
  • Android SDK
  • Room / SQLite
  • AlarmManager
  • Unit testing
  • GitLab CI/CD
